🎯 How to Add Anchor Tags (3 Easy Steps)

Step 1: Create a heading in your content
<h2>Introduction</h2>
Step 2: Select the heading text, click the "Anchor" button (flag icon 🚩), and give it a name like "introduction"
Step 3: Create a link somewhere in your article, select text, click "Link" button 🔗, and enter: #introduction

Example: Table of Contents

<h3>Table of Contents</h3> <ul> <li><a href="#intro">Introduction</a></li> <li><a href="#benefits">Key Benefits</a></li> <li><a href="#conclusion">Conclusion</a></li> </ul> <h2 id="intro">Introduction</h2> <p>Your content here...</p> <h2 id="benefits">Key Benefits</h2> <p>Your content here...</p> <h2 id="conclusion">Conclusion</h2> <p>Your content here...</p>

💡 Pro Tips

  • Use H2 for major sections, H3 for subsections
  • Add alternative text to all images for SEO
  • Use anchor tags for articles longer than 3 sections
  • Click "Source" button to view/edit raw HTML
  • Preview your content before publishing
  • Break up long paragraphs for better readability
  • Use lists and tables to organize information
  • Add call-to-action boxes with custom styling
